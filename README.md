# 场景切换检测

基于 RGB 三维直方图的场景切换检测器，只用 Python 标准库。

## 算法

### 直方图

`histogram(frame, bins=8)` 把 R、G、B 三个通道各自独立分成 `bins` 个桶，
返回长度为 `3 * bins` 的扁平列表：先是 R 的 `bins` 个桶，然后是 G、B。
每个桶的值是该通道内落入该桶的像素占比，因此整个列表元素之和为 1。

三个通道全部参与，红色场景与绿色场景即使亮度相同也能区分（两者的 R/G
分布完全相反）。`bins` 越大，量化越细：`bins=4` 时 0 与 31 落在同一桶、
距离为 0；`bins=32` 时同一对颜色距离明显大于 0。

### 距离

`hist_distance(a, b)` 对每个通道分别计算一维 **EMD（推土机距离 /
Wasserstein-1）**，再对三个通道取平均：

```
d = (emd_R + emd_G + emd_B) / 3
```

单通道 EMD 的实现是累积分布函数差值的积分，最后除以 `bins - 1`
（桶索引 `0..bins-1` 对应值域 `0..255`）归一：

```
emd = (1 / (bins - 1)) * Σ_{k=0}^{bins-2} |CDF_a(k) - CDF_b(k)|
```

**归一化后的物理含义**：`d ∈ [0, 1]`。0 表示两帧的颜色分布完全相同，
1 表示分布完全不相交。阈值 0.25 表示：平均每个颜色通道需要把约 25% 的
值域（0-255 中约 64 个灰阶）的像素质量整体搬移，才能从上一帧变成当前帧。
与旧的“逐桶绝对差求和”不同，EMD 对颜色偏移的大小敏感——把整体亮度挪
10 个灰阶与挪 200 个灰阶不再得到相同的距离。

### 检测

`detect(frames, threshold=0.25, bins=8)` 先算逐帧距离曲线，再做后处理：

1. **候选**：相邻帧距离 `>= threshold` 的帧。
2. **闪光抑制**：若第 `i` 帧“进入”和“离开”都超阈值，但 `i-1` 与 `i+1`
   两帧彼此距离低于阈值，说明是单帧闪光，计入抑制集合，不产生切换点。
   真正的切换会改变后续场景，`i-1` 与 `i+1` 仍然差异很大，不会被误杀。
3. **渐变合并**：候选按时间聚段，间隔不超过 2 帧的候选算同一段。段内
   至少 3 个候选认为变化在持续累积，是渐变，只报告段末一个点，类型为
   **“渐变末尾”**。段末若相对段内其余步长有明显尖峰（>= 1.5 倍），说明
   是渐变后紧接的硬切，该帧单独按 **“突变”** 报告，其余部分再按渐变处理。
4. 其余候选逐个报告为 **“突变”**。

返回值是按帧号排序的列表，元素形如
`{"frame": 10, "distance": 0.5238, "kind": "突变"}`。
`threshold` 可配置：调低会露出更多弱变化，调高则更严格。

## 运行

```
python -m scenecut.cli data/frames.raw --size 64,48 --frames 40 --threshold 0.25
python -m scenecut.cli data/frames.raw --size 64,48 --frames 40 --bins 32 --threshold 0.25
python -m scenecut.cli data/frames.raw --size 64,48 --frames 40 --threshold 0.10 0.25 0.60
python -m pytest tests -q
```

CLI 会打印逐帧距离曲线、切换点列表（含突变/渐变末尾标注）；`--threshold`
接受多个值时还会输出不同阈值下的检出数量对比。结果同时写入 `--out`
（默认 `cuts.json`），包含 `distance_curve`、`cuts` 与
`threshold_comparison` 三个字段。

`frames.raw` 40 帧 64x48 裸 RGB：第 0 到 9 帧蓝天，第 10 帧突变到红色，
第 20 到 29 帧红到绿渐变，第 30 帧突变到暗场。真实的切换点在第 10 帧与
第 30 帧。

## 实测（`--bins 8 --threshold 0.25`）

第 9 到 11 帧：

| 帧 | 距离 | 结果 |
|----|------|------|
| 9  | 0.000000 | — |
| 10 | 0.523810 | **切换（突变）** |
| 11 | 0.000000 | — |

第 29 到 31 帧：

| 帧 | 距离 | 结果 |
|----|------|------|
| 29 | 0.047619 | — |
| 30 | 0.333333 | **切换（突变）** |
| 31 | 0.000000 | — |

渐变段（第 20 到 29 帧）的距离最大值为 **0.047619**，低于阈值 0.25，
整段没有产生任何切换点。最终检出：**第 10 帧与第 30 帧，均为突变**。

阈值对比（bins=8）：

| 阈值 | 检出数量 | 检出帧 |
|------|----------|--------|
| 0.60 | 0 | — |
| 0.25 | 2 | 10, 30 |
| 0.10 | 2 | 10, 30 |
| 0.02 | 3 | 10, 29（渐变末尾）, 30 |

单个闪光帧（白帧插入蓝天序列，进入/离开距离均为 0.5714）不会产生
切换点：离开后与闪光前画面一致，被闪光抑制逻辑滤掉。

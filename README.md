# 场景切换检测

骨架能读裸帧、能算直方图、能出切换点，但检测结果会把渐变也报成切换。

## 已知缺口

- `histogram` 只用 R 通道，绿色与蓝色变化完全看不见，红到绿这种切换测不出来。
- 只有 8 个桶，颜色分布接近的两个场景距离也很小，区分度不足。
- `hist_distance` 用绝对差求和，没有归一，8 个桶的理论最大值是 2，阈值 0.25 的实际含义模糊。
- 阈值固定，色彩渐变段每帧都有距离累积，会被误报成密集切换。
- 没有做帧序连续性检查，单个闪光帧也会被算成一次切换。
- 没有输出各帧的距离曲线，无法回看阈值定得是否合适。

## 运行

```
python gen_samples.py
python -m scenecut.cli data/frames.raw --size 64,48 --frames 40 --threshold 0.25 --out cuts.json
python -m pytest tests -q
```

`frames.raw` 40 帧 64x48 裸 RGB：第 0 到 9 帧蓝天，第 10 帧突变到红色，第 20 到 29 帧红到绿渐变，
第 30 帧突变到暗场。真实的切换点在第 10 帧与第 30 帧。
